# Proveniência do código

O código público corresponde ao estado científico congelado das análises. A preparação para publicação incluiu ajustes editoriais e de interoperabilidade, preservando integralmente a lógica científica. Não foram modificadas fórmulas, populações analíticas, configurações dos modelos, previsões ou resultados científicos.

Fórmulas, filtros, populações, sementes, folds, modelos, hiperparâmetros e resultados não foram alterados.

`threshold_classification_metrics.py` aplica a classificação dependente de limiar a previsões OOF previamente geradas. A coluna `train_event_rate` registra a prevalência do respectivo fold de treinamento necessária a essa etapa. Essa integração não reajustou modelos nem regenerou previsões OOF.
